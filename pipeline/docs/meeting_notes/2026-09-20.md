## 2. Variables + hypotheses (per today's read-through of the proposal draft)

The proposal draft ([STX AQ Proposal.docx](https://tamucc-my.sharepoint.com/:w:/r/personal/jtrevino79_islander_tamucc_edu/_layouts/15/Doc.aspx?sourcedoc=%7B1F7E1BF3-856B-46A6-8348-2B1D8BF57D76%7D&file=STX%20AQ%20Proposal.docx&action=default&mobileredirect=true&DefaultItemOpen=1&web=1))
is now the authoritative live version; this scope doc mirrors its structure. Highlights from today's read:

- **Primary RQ.** Random-Forest prediction of *transport direction* and
  *concentration* of SO₂, O₃, and (where coverage permits) PM2.5 from routine
  meteorological observations, 2015–2025, in the Refinery-Row area.
- **Secondary RQ.** Do the resulting directional patterns vary systematically
  by season and year, and is that variation consistent with sea-breeze /
  frontal-reversal control?
- **Exploratory.** Can the same model support a categorical AQI-band
  classifier for public-facing early warning?
- **Future.** Can predicted pollutant transport patterns improve prediction
  of respiratory health outcomes when integrated with the BREATHE-CC cohort
  (once ≥ 150-participant cohort profile is available)?
- **H1** — direction predicted more accurately than concentration
  (persistent sea-breeze anchors direction; concentration reflects
  unobserved emission-source dynamics).
- **H2** — top RF features expected to be season, wind speed, and
  temperature.
- **H3** — wind-derived predictors dominate SO₂ models; photochemical
  predictors (solar irradiance, temperature) dominate O₃ models.
- **H4 (exploratory)** — evaluate performance across AQI bands; check
  how error scales on high-concentration days.

## 4. Analysis stack (locked today)

- **Platform:** Python 3.6+ (data), HYSPLIT (backward trajectories).
- **Packages:** scikit-learn (RF + metrics), matplotlib, seaborn, windrose,
  NOAA HYSPLIT/READY.
- **Phase 1 — Acquisition + preprocessing.** Neon-hosted TCEQ hourly
  pollutant data + OpenWeather regional met + site-specific TCEQ met.
  Python preprocessing removes null/negative values and standardises
  units.
- **Phase 2 — EDA.** Distributions, correlations, pollution roses; HYSPLIT
  backward trajectories grouped by season for elevated-SO₂ / -PM2.5
  hours (test whether inbound air passes over Refinery Row).
- **Phase 3 — Predictive modelling.** RF for hourly SO₂, PM2.5, O₃.
  Two model families evaluated: (1) combined multi-pollutant model,
  (2) per-pollutant models with the same features. Metrics: RMSE, MAE,
  R², r.
- **Phase 4 — Interpretation.** RF feature importance to answer "*why*"
  each prediction landed where it did.
- **Phase 5 — Visualisation.** Site map (with Refinery-Row overlay),
  seasonal pollution + wind roses, HYSPLIT trajectory-frequency
  surfaces, observed-vs-predicted scatter with 1:1 line, feature-
  importance bar charts.
